# Admin usability repair — 31 October 2026

Scope: parent/guardian editing, roster column customization, and club/staff settings.

## Implemented

- Parent/guardian card opens a dedicated editor. Add a new contact, link an existing person, or edit a linked primary-family contact's name, email, telephone, relationship and primary-contact flag. Contact and relationship writes are atomic, require a reason and retain audit history. Existing-person edits check the last recorded timestamp and relationship state. No implicit custody, consent, login or emergency-contact grants.
- Roster offers 13 available columns, show/hide and ordering controls, sorting, squad/status filters, search, 25-row pagination and named browser-local views scoped to the signed-in user, role and club. Squad names and contact information replace the previous count-only display. No medical or financial fields are added to the roster query.
- Club settings separates Club details, Staff & access, Teams/seasons/locations and Activity history. Club names are editable, staff can be added and assigned existing delegable roles, assignments show scope, removal requires confirmation, and role descriptions explain responsibility. A person record is explicitly distinguished from a sign-in account.
- Club edits enforce organization scope and detect conflicting changes. Existing self-deactivation controls remain.
- Icons API creates its database client only when handling a request, allowing compilation without server secrets and returning 503 when its configuration is absent.
